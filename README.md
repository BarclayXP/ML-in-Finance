# ML in Finance

Lab logbooks for the Machine Learning in Finance module.

As instructed, this repository holds the lab logbook for each week —
a Word document containing screenshots of the code and the results produced
at the end of that week's practical session — together with the screenshot
as a PNG. The Jupyter notebooks and datasets are not uploaded.
