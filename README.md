# ML in Finance

Lab logbooks for the Machine Learning in Finance module.

As instructed, this repository holds the lab logbook for each week —
a Word document containing screenshots of the code and the results produced
at the end of that week's practical session — together with the screenshot
as a PNG. The Jupyter notebooks and datasets are not uploaded.

## Contents

```
Week1/Week1.docx    Week 1 — NumPy: arrays, arange, shape and reshape
Week1/week1.png     Week 1 screenshot
week2/Week2.docx    Week 2 — Pandas: DataFrames, groupby and apply
week2/week2.png     Week 2 screenshot
week3/Week3.docx    Week 3 — Pandas and Seaborn: exploring telecom churn data
week3/week3.png     Week 3 screenshot
week4/Week4.docx    Week 4 — MLP neural network: S&P 500 index price forecast
week4/week4.png     Week 4 screenshot
```
